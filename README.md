# YANAWA!

> 지역과 운동 종목을 기반으로 사용자가 생활체육 모임을 생성하고 참여할 수 있는 실시간 매칭 서비스

YANAWA!는 탁구, 배드민턴, 테니스 등 생활체육을 즐기는 사용자가
주변의 운동 모임을 찾고 직접 모임을 생성하여 함께 운동할 사람을 모집할 수 있는 웹 서비스입니다.

단순 게시판 형태가 아닌 회원 인증, 종목별 실력 프로필, 참가 승인,
실시간 채팅, 출석 및 평가 기능까지 하나의 흐름으로 구현했습니다.

---

## 주요 기능

### 사용자

- 회원가입 / 로그인 / 로그아웃
- 세션 기반 인증
- 사용자 정보 조회 및 수정
- 비밀번호 변경 및 회원 탈퇴
- 프로필 이미지 등록 및 변경
- 종목별 실력 프로필 관리

### 모임

- 생활체육 모임 생성 / 조회 / 수정 / 삭제
- 종목, 지역, 날짜, 키워드 기반 모임 검색
- 모임별 최대 인원 설정
- 즉시 승인 / 모임장 승인 방식 선택
- 모임별 요구 실력 설정
- 모집 / 마감 / 완료 / 취소 상태 관리

### 참가

- 모임 참가 신청 및 취소
- 참가 신청 승인 / 거절
- 참가자 강퇴
- 신청자의 해당 종목 실력 확인
- 출석 / No-Show 관리

### 실시간 채팅

- Flask-SocketIO 기반 WebSocket 채팅
- 모임 승인 후 채팅방 자동 참여
- 참가 취소 및 강퇴 시 채팅방에서도 제거
- 채팅 메시지 저장 및 조회

### 이미지

- 프로필 이미지를 AWS S3에 저장
- DB에는 S3 Object Key만 저장
- Private Bucket + Presigned URL 방식으로 이미지 조회
- 프로필 이미지 변경 시 기존 S3 Object 자동 삭제
